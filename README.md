# Credit Risk Modeling with SQL and Machine Learning

This project simulates a real-world banking pipeline using SQL and machine learning.

## 🧠 Pipeline
1. Create a relational database (SQLite)
2. Simulate customers and transactions
3. Query data using SQL
4. Feature engineering (customer behavior)
5. Train ML model (Logistic Regression)
6. Evaluate results

## 🛠 Technologies
- Python
- SQLite
- Pandas
- Scikit-learn

## 🚀 How to run
python main.py

## 📊 Features used
- Total transaction amount
- Average transaction amount
- Number of transactions
- Account balance proxy

## 📌 Why this matters
Banks rely heavily on SQL + ML pipelines for risk modeling and decision systems.
